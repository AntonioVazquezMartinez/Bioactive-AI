# Animaciones explicativas (carpeta `animaciones/`).
#
# **Deliberadamente fuera de `requirements.lock`.** El lock fija el entorno con
# el que se ejecutaron los notebooks y se midieron las cifras del proyecto;
# Manim arrastra cairo, pango, ffmpeg y una cadena de dependencias gráficas que
# no tienen nada que ver con reproducir un número. Mezclarlos haría más frágil
# justo lo que el lock existe para proteger.
#
#     uv venv --python 3.12 env-anim
#     uv pip install --python env-anim -r requirements-animaciones.txt
#
# Hace falta `ffmpeg` en el sistema (`brew install ffmpeg`). **No hace falta
# LaTeX**: las escenas usan `Text` y no `MathTex`, a propósito, para que
# cualquiera pueda renderizarlas sin una instalación de TeX.
manim>=0.19
# `tests/test_figuras.py` se salta solo si no hay Manim, así que en el entorno
# del lock —donde corre el `pytest` del CI— nunca se ejecuta. Aquí sí, y por eso
# el paso de animaciones lo corre antes de renderizar: las guardas de `figuras`
# son baratas de probar y caras de descubrir en un fotograma.
pytest>=8.0
